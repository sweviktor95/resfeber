# Resfeber

Ett resespel i webbläsaren i Globetrotters anda. Res jorden runt, gå runt på stadskartor, ta jobb, fotografera sevärdheter åt Världsresenärernas klubb och bli ordförande.

**Spela:** https://sweviktor95.github.io/resfeber/

- Fungerar på mobil och dator.
- Helskärm: tryck på ⛶ (Android/dator). På iPhone: Dela → "Lägg till på hemskärmen".
- Allt (grafik, ljud, kartor) genereras i koden – inga externa bilder eller ljudfiler.
